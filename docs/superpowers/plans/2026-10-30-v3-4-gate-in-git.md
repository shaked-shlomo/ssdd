# v3.4 — The Gate Lives in Git Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The git pre-commit is the only review gate; the harness hooks keep
only what holds it in the loop, what guards an outward action, and two
conveniences, so SSDD runs the same on any harness.

**Architecture:**
- `review-gate.mjs` loses its harness mode and completion stamps. `--stamp`
  keys the work tree through a scratch index, and `judge()` lets a clean
  stamp carry over a comment-only change, read from a new dependency-free
  scanner, `comment-strip.mjs`.
- `git-guard.mjs` keeps two blocks (`-n`/`--no-verify`, plain
  `core.hooksPath` writes) plus `extraRules`, and warns on bulk add and
  amend through `additionalContext` / `agent_message`.
- `ssdd-config.mjs` ignores nine removed keys and names them; it gains
  `reviewGate.commentReviewer` and a stricter `dormantHook`.
- `bin/ssdd.mjs` reports the seeded Claude Code wiring against its template.

**Tech Stack:** Node ≥ 22, ES modules, zero dependencies, the git CLI,
`node:test`.

**Spec:** `docs/specs/v3.4.md` (Decisions 1–7, Clarify 1–14).
**Branch:** `claude/v3-6-plan-359ba7`.

## Global Constraints

- Zero npm dependencies; Node ≥ 22. CI runs Node 22 and 24.
- Tests: `node --test bin/*.selftest.mjs mechanisms/hooks/*.selftest.mjs
  packs/*/*.selftest.mjs`: 1327 pass at `7507dec`.
- The stamp file stays `.git/ssdd-review-stamp.json`, version 2, key
  `srcMode:srcBlob→dstMode:dstBlob`. Nothing new is written to it.
- No new hook event, git hook or block (spec, Footprint).
- A removed config key never makes a config broken (Decision 6).
- `--check` and `--pre-commit` write nothing: the stamp file and the index
  are byte-identical after them.
- `process/SDD.md` stays ≤ 11,000 bytes (`bin/repo.selftest.mjs:180`).
- Reviewer edits start from 3.3.2's text (on this branch since `7507dec`).
- Never write to `~/Developer/prizma` or `~/Developer/Hatedate`; real-data
  runs use scratch clones in the session scratchpad.
- Messages keep their leading text where a test or a user matches it
  (`[ssdd-review-gate] the staged diff owes reviews:`, `Blocked:`).

## Acceptance criteria

Each names the Decision (D) or Clarify item (C) it proves.

- **AC1 — The pre-commit is the gate (D1).** Through an armed pre-commit in
  a scratch repo, with a routed file unstamped: `git commit -am`, `git
  commit <path>`, `git add f && git commit` in one shell string, and `git
  -C <worktree> commit` from the main checkout are each refused (exit 1,
  HEAD unchanged), and each lands after `--stamp`. `SSDD_REVIEW_SKIP=1 git
  commit` lands with the banner. The block message's stamp command ends in
  `--repo <the committing work tree>`.
- **AC2 — Stale wiring is harmless (C9).** `review-gate.mjs` with no mode,
  fed a Claude PreToolUse, SubagentStart or SubagentStop payload, exits 0
  with empty stdout; fed a Cursor `beforeShellExecution` payload, it prints
  `{"permission":"allow"}`. git-guard fed an Edit payload on
  `.git/ssdd-review-stamp.json` exits 0.
- **AC3 — The harness gate is gone (D1, D2).** Neither template wires
  `review-gate.mjs`; `settings-hooks.json` has 5 entries and Cursor's
  `hooks.json` 5. `model-id.mjs`, `review-gate.shapes.selftest.mjs` and
  `review-stamp.selftest.mjs` don't exist; `git-cmd.mjs` exports no
  `commandStart`, `gitInvocation` or `isCommit`. `git grep -n -e
  subagentHook -e readTranscript -e parseVerdict -e modelAllowed -e
  reviewerModelSets -e ssdd-review-dispatch -- mechanisms bin adapters`
  prints nothing.
- **AC4 — Stamping before `git add` (D2, C4, C5).** A routed file edited
  but not staged, and an untracked routed file, are stamped by `--stamp`;
  `git add` of the same content then commits with no new stamp. A symlink,
  an exec-bit change and a CRLF file under `eol=lf` key as `git add` does.
  `--stamp --files` refuses an ignored, an unchanged and an unrouted file,
  writing nothing. A file staged and then edited is stamped on its
  work-tree blob, `--stamp` prints `the staged copy differs`, and the
  commit stays owed until the file is added.
- **AC5 — Reviewers read `git diff HEAD` (D2, C13).** Step 1 of all seven
  reviewer files says `git diff HEAD`; none says `git diff --staged`.
- **AC6 — The comment-only carry (D3, C14).** After a full stamp, a
  comment-only edit to a routed `.ts` file leaves every routed reviewer but
  the comment reviewer met; the comment reviewer owes the file with a delta
  line; the pre-commit's note names the carried stamps. Nothing carries for:
  a code change; a tool-read comment; a `.py` file; a stamped blob that's
  gone; a changed HEAD side; a mode change; a stamp with `issues > 0`; a
  repo whose comment reviewer isn't routed to the file. `--check` and
  `--pre-commit` leave the stamp file byte-identical.
- **AC7 — The scanner (D3, C2).** `comment-strip.selftest.mjs` passes the
  grammar cases in Task 7. Over prizma's and SSDD's history, against the
  TypeScript-printer oracle, no pair the scanner calls comment-only is a
  code change.
- **AC8 — docs-sync checks comment claims (D3).** `docs-sync-reviewer.md`
  has the comment-only section.
- **AC9 — git-guard (D4, C7).** Blocked, under both payloads: `commit -n`,
  `--no-verify`, `git -c core.hooksPath=x`, `git config core.hooksPath x`,
  `git config --unset core.hooksPath`, `git config set core.hooksPath x`,
  and the example's force-push rule. Allowed with a warning: `git add -A`,
  `git add .`, `git add --all`, `git commit --amend` (Claude:
  `hookSpecificOutput.additionalContext` only; Cursor: `permission` allow
  plus `agent_message`). Allowed silently now: the `GIT_CONFIG_*` env
  forms, `--unset-a`, `$(…)` before the key. A config with
  `blockNoVerify: false` still blocks `-n`.
- **AC10 — Lint warns at commit (D5, C1).** With a lint finding and the
  routed files stamped, a real commit lands; stderr carries the finding.
- **AC11 — The config (D6).** A config holding each of the nine removed
  keys loads with no `error`; `obsolete` lists them; `status` and `update`
  print them. `cfg.reviewGate.commentReviewer` defaults to
  `docs-sync-reviewer`. `config.example.json` has none of the nine and
  passes `review-gate.selftest.mjs`'s example-routes cases.
- **AC12 — Wiring and armed (D7, C6, C8).** In a scratch repo installed at
  `v3.3.2` and updated to this branch, `update` and `status` list the four
  dropped entries as safe to remove; a `.claude/settings.json` missing
  SessionStart lists it as missing; an entry with another path or an env
  prefix matches. The session view and `status` call a pre-commit that
  doesn't run `review-gate.mjs --pre-commit` dormant (a scratch clone of
  Hatedate), and prizma's customized one armed.
- **AC13 — Release (C12).** `VERSION` is `3.4.0`; CHANGELOG `[3.4.0]` has
  Removed / Changed / Upgrade; README, `SDD.md` §4, `docs/limitations.md`,
  `AGENTS.md`, the `CLAUDE.md` template, both adapter READMEs and
  `docs/usage.md` describe one gate. All tests pass; the footprint is
  recorded against the spec's.

## Review Focus

- **A path with a space or non-ASCII letters** through the scratch-index
  `add` (`--pathspec-file-nul`) and the work-tree key parse → test in
  Task 2.
- **A linked worktree:** the scratch index is the worktree's (`rev-parse
  --git-path index`), not the main checkout's → test in Task 2.
- **An unborn branch** (no HEAD yet): `--stamp` on the first commit's files,
  and the carry with no HEAD side → tests in Tasks 2 and 8.
- **A blob that isn't UTF-8** (a binary `.js` fixture) → no carry, no
  throw; a BOM → classified or null, never a throw → tests in Tasks 7
  and 8.
- **A hand-edited stamp entry** (`issues: "2"`, a malformed key) → no
  carry and no throw in `judge()` → test in Task 8.
